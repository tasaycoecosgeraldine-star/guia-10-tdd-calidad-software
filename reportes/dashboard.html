Resultados obtenidos

Se desarrolló un módulo de procesamiento de pagos con Java 17, Maven, JUnit 5 y Mockito, aplicando la metodología TDD.

Se verificó el cálculo del ITF con la condición académica de transacciones superiores a S/ 1,000 y se simuló el servicio bancario mediante Mocks.

Las diez pruebas unitarias se ejecutaron exitosamente y el reporte JaCoCo mostró 100% de cobertura de instrucciones, ramas y líneas.

Conclusión

La práctica permitió comprender la importancia de las pruebas unitarias en la calidad del software. La metodología TDD ayudó a desarrollar funcionalidades verificables desde el inicio, mientras que Mockito permitió aislar las dependencias externas. Finalmente, JaCoCo permitió comprobar la cobertura obtenida en la lógica de negocio.
